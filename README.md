# Devlog Duo

Clem과 Ryan이 함께 쓰는 GitHub Pages용 개발일지입니다.

## 사용 방법

1. 이 폴더를 GitHub 저장소에 올립니다.
2. 저장소의 **Settings → Pages**에서 배포 브랜치를 선택합니다.
3. 생성된 GitHub Pages 주소로 접속합니다.

기록은 브라우저 `localStorage`에 저장됩니다. 다른 브라우저나 사람과 데이터를 옮길 때는 오른쪽의 **Export JSON / Import JSON**을 사용하세요. 완전한 실시간 공유가 필요하면 추후 Firebase 또는 Supabase 같은 백엔드를 연결해야 합니다.
